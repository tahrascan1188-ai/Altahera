# نظام إدارة الطاهرة الطبي المتكامل ومساعد واتساب الذكي (Altahera Management System & AI WhatsApp CRM)

نظام إلكتروني متكامل لإدارة الفروع ومراقبة الأجهزة الطبية وتتبع حركاتها وإشعاراتها، مدمج معه **مساعد واستعلامات واتساب الطبية الذكية** (Live CRM). يعتمد النظام على واجهة مستخدم متطورة وحديثة وسريعة الاستجابة (Glassmorphic Responsive UI) ويعمل بالارتباط مباشرة بقاعدة بيانات سحابية ومحلية لضمان السرعة والمركزية.

---

## 🚀 المميزات الرئيسية (Key Features)

### 1️⃣ مساعد واستعلامات واتساب الطبية الذكية (AI WhatsApp Live CRM)
* **واجهة المحادثات الحية (Live Chat Directory):** عرض قائمة المحادثات النشطة مباشرة من هاتف الواتساب المرتبط مع عداد الرسائل غير المقروءة والبحث الفوري بالاسم أو الرقم أو جزء من النص.
* **التوليد الذكي عند الطلب (On-Demand AI Reply):** يتم توليد الردود بالذكاء الاصطناعي يدويًا بضغطة زر لكل رسالة، مما يضمن التحكم الكامل للموظف ويوفر 100% من استهلاك الكوتا وحمايتها من المحادثات العادية أو التحيات.
* **الرد الموحد الذكي (Batch Messages AI Reply):** إمكانية تحديد عدة رسائل متتالية مرسلة من المريض وتوليد رد طبي موحد وشامل لكل استفساراته بضغطة واحدة.
* **تحليل الصور والروشتات:** عند وصول صورة روشتة أو تحليل من مريض، يقوم الذكاء الاصطناعي بقراءتها آلياً واستخراج الفحوصات المطلوبة والبحث الفوري عن أسعارها وتعليماتها في قاعدة البيانات وعرضها على الموظف للمراجعة قبل الإرسال.
* **تحميل فوري للصور:** تظهر الصور المرفقة داخل فقاعات المحادثة مع أيقونة تحميل فوري، لحفظ الروشتات الطبية على جهاز الكمبيوتر بضغطة واحدة.
* **نظام تسريع التصفح (Lazy Loading):** يتم تحميل سجل المحادثات والرسائل فوراً (أقل من 50 مللي ثانية) عن طريق تأجيل تحميل الصور حتى يطلبها الموظف، مما يضمن أداء فائق السرعة.

### 2️⃣ حماية وسرية بيانات الـ API & الجلسات
* **إعدادات مغلقة للمدير فقط (Admin-Only Settings):** تظهر إعدادات مفاتيح الـ API لـ Gemini وحفظ التعليمات البرمجية فقط للحسابات ذات صلاحية `Administrator` (مثل حساب `admin`)، بينما تُحجب تماماً عن موظفي الاستقبال لمنع التلاعب بالمفاتيح أو كشفها.
* **تدوير المفاتيح الذاتي (API Key Rotation & Failover):** يدعم الخادم تسجيل 3 مفاتيح API مختلفة لـ Gemini؛ يقوم النظام بتدويرها تلقائياً. في حال وصول المفتاح الأول للحد الأقصى للاستخدام (429 Quota Exceeded)، ينتقل الخادم فوراً وبسلاسة للمفتاح الثاني ثم الثالث لضمان استمرارية الخدمة.
* **تسجيل الخروج الآمن (WhatsApp Logout):** زر مخصص للمدير فقط لقطع اتصال الواتساب وتسجيل الخروج الآمن من الخادم لحماية خصوصية الحساب المرتبط وتطهير الجلسة تماماً.
* **منع التداخل البرمجي (Chat Collision Lock):** قفل تلقائي للمحادثة المفتوحة حالياً من قبل موظف استقبال، وتنبيه بقية الموظفين بأن زميلهم يراجع المحادثة الآن لمنع إرسال ردود مكررة أو متداخلة لنفس المريض.

### 3️⃣ إدارة الفروع والأجهزة الطبية والفحوصات
* **لوحة تحكم تفاعلية (Dashboard):** إحصائيات سريعة ومخططات بيانية لتعقب حالة الفروع ونشاطات الأجهزة الطبية.
* **مراقبة وحكم بالأجهزة الطبية (Devices Monitoring):** توثيق دقيق لحركة كل جهاز طبي بين الفروع، وتغيير حالات الجهاز (متاح للعمل، صيانة، خارج الخدمة) مع تسجيل سبب التحويل أو العطل.
* **إدارة الفحوصات الطبية (Tests Directory):** تسعير تحاليل المعامل وفحوصات الأشعة وتحديث شروطها وتعليماتها وتنسيقها محلياً ومزامنتها سحابياً.
* **إدارة جدول الأطباء (Doctors Scheduler):** ترتيب أسبوعي لمواعيد أطباء الفروع وتوضيح حالة التوافر الفعلي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** HTML5, Vanilla CSS3 (ألوان متناسقة ومؤثرات حركية فائقة), JavaScript (ES6+), Socket.io Client.
- **الخادم (Backend):** Node.js, Express, Socket.io (للاتصال الفوري ومزامنة الرسائل والقفول في نفس اللحظة).
- **قواعد البيانات (Databases):** 
  - **SQLite3:** لتخزين إعدادات الـ API والمساعد المحلي والمسودات بسرعة وأمان.
  - **Google Sheets API:** الحفظ السحابي المركزي لربط بيانات الفروع والأطباء والأجهزة وجداول الأسعار.
- **محرك الواتساب والذكاء الاصطناعي:**
  - **whatsapp-web.js / Puppeteer:** لتشغيل نسخة واتساب ويب وإرسال واستقبال الرسائل والصور وإدارة الجلسات بشكل خفي وسريع بدون الحاجة لـ API مدفوع.
  - **Google Generative AI SDK (@google/generative-ai):** للربط بنماذج ذكاء اصطناعي متطورة وسريعة الاستجابة (`gemini-2.5-flash`).

## 🔍 طريقة التشغيل والاستخدام (Setup & Run)

1. **بدء تشغيل الخادم:**
   * اضغط مرتين على ملف **`run.bat`** الموجود بمجلد المشروع.
   * سيتم تثبيت الحزم تلقائياً (في حال تشغيله لأول مرة) ثم يفتح المتصفح تلقائياً على الرابط: **[http://localhost:3000](http://localhost:3000)**.

2. **تسجيل الدخول للنظام:**
   * استخدم الحساب الرئيسي للمدير لإعداد وتفعيل الاتصال:
     * **اسم المستخدم:** `admin`
     * **كلمة المرور:** `admin`

3. **إعداد مفاتيح الذكاء الاصطناعي (متاح للمدير فقط):**
   * من القائمة الجانبية اختر **"مساعد واتساب الذكي"**.
   * اضغط على أيقونة الترس (`⚙️`) بالأعلى واكتب مفاتيح الـ API الخاصة بك (يمكنك وضع مفتاح واحد أو حتى ثلاثة مفاتيح لتدوير الاستخدام)، واكتب التوجيهات الطبية المناسبة ثم احفظ الإعدادات.

4. **ربط واتساب بالمنصة:**
   * اضغط على زر **"الربط"** ثم اختر **"ربط الجهاز الآن"**.
   * سيظهر لك رمز الـ QR كود فوراً، قم بمسحه باستخدام تطبيق الواتساب على هاتفك (الأجهزة المرتبطة). بمجرد إتمام المسح ستتحول الدائرة إلى اللون الأخضر وسيتم تحميل محادثاتك النشطة مباشرة!
